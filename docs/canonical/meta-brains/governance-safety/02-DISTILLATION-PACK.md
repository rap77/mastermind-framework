# Governance & Safety Brain — Distillation Pack

## 1. Context

- **Target brain:** Governance & Safety Brain
- **Brain ID:** MB-05
- **Expert pack:** `01-EXPERT-PACK.md`

## 2. Distillation Goals

This pack should produce doctrine that helps MasterMind answer:

1. when a decision may become action
2. what actions require stronger gates
3. who may veto what
4. when the system must escalate to a human
5. what minimum auditability is required

## 3. Core Principles to Extract

- traceability before autonomy
- actions differ by reversibility and risk
- veto is a safety mechanism, not a political nuisance
- escalation is a design feature
- auditability is part of correctness
- confidence alone never justifies high-risk action

## 4. Frameworks / Methods

- action gating
- veto design
- escalation thresholds
- audit/control matrices
- reversible vs irreversible action framing
- failure containment logic

## 5. Decision Criteria

- can this action cause real harm?
- is the action reversible?
- what evidence is required before acting?
- who must be able to block this?
- when must a human review the decision?
- what trace must exist afterward?

## 6. Anti-Patterns

- consensus without control
- no audit trail for meaningful actions
- no distinction between low-risk and high-risk actions
- assuming smart agents need fewer controls
- escalation only after damage is visible

## 7. Operational Interpretation

For MasterMind, this distillation should directly inform:

- decision rights matrix
- decision record structure
- live-action gating
- project adoption safety model
- finance/trading progression rules
