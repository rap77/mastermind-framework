# Example Project Adapter

## 1. Project Identity

- **Project name:** Trading Pilot Alpha
- **Project type:** External pilot / finance trading system
- **Primary niche:** Finance / Trading

## 2. Project Goal

Use MasterMind to help design and govern a trading software system that uses historical data, robust validation, and gated progression from research to paper/live stages.

## 3. Why MasterMind Is Being Used Here

To improve:

- strategic framing
- quant validation quality
- risk/governance rigor
- software translation from finance logic

## 4. Selected Brains

### Meta-brains

- Platform Architecture Brain
- Agent Runtime & LLM Ops Brain
- Governance & Safety Brain

### Niche brains

- F1 Trading Strategy
- F2 Quant Research
- F3 Risk
- F5 Execution
- F6 Governance
- F7 Evaluator

## 5. Project-Local Knowledge

Examples of things that remain local:

- chosen broker constraints
- local data feed issues
- project-specific infra limitations
- team-specific deployment restrictions

## 6. Candidate Promotion to Core

Examples of things that may later promote:

- better paper-to-live gating pattern
- improved decision record structure
- reusable risk/governance workflow pattern

## 7. First Workflow Target

The first MasterMind-supported workflow should be:

> evaluate whether a first trading strategy should progress from hypothesis to research/paper-trading stage

## 8. Notes

This example shows how the framework remains reusable while the project keeps its niche-specific logic local until proven reusable.
