# Brain Factory Architecture

## 1. Propósito

La Brain Factory es la capacidad de MasterMind para:

- descubrir nuevos nichos
- definir qué brains necesita ese nicho
- recomendar expertos
- reunir fuentes
- destilar conocimiento
- generar nuevos brains listos para operar
- permitir que esos brains mejoren con experiencia

## 2. Definición

> Brain Factory es la capa de MasterMind que transforma un nicho o problema nuevo en un sistema experto operable compuesto por brains especializados.

## 3. Flujo completo

```text
Nicho nuevo
→ Niche Discovery
→ Brain Topology Design
→ Expert Recommendation
→ Source Acquisition
→ Distillation
→ Brain Scaffolding
→ Validation
→ Runtime Integration
→ Experience Learning
```

## 4. Capas

### A. Niche Discovery

Identifica subdisciplinas, decisiones clave, riesgos y restricciones.

### B. Brain Topology Design

Transforma el mapa del nicho en un conjunto de brains.

### C. Expert Recommendation Engine

Selecciona expertos y prioriza fuentes por brain.

### D. Source Acquisition

Recolecta libros, artículos, papers, cursos, podcasts y documentación.

### E. Distillation Engine

Convierte fuentes en conocimiento operativo.

### F. Brain Scaffolding

Genera identidad, rol, límites, triggers y configuración del brain.

### G. Validation Layer

Evalúa si el brain cubre un hueco real y si merece entrar al sistema.

### H. Runtime Integration

Conecta el nuevo brain al orquestador, routing y memoria.

## 5. Principios

- nicho primero
- expertos antes que prompts
- destilación operativa
- validación antes de integrar
- aprendizaje posterior controlado

## 6. Posicionamiento final

> MasterMind no solo orquesta inteligencia especializada: también la diseña, la fabrica y la mejora.
