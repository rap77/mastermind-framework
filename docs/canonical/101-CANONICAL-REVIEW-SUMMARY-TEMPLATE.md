# Canonical Review Summary Template

## 1. Propósito

Definir la plantilla estándar para cerrar un ciclo de canonicación con un resumen completo, fácil de revisar y comparar.

## 2. Tesis central

Cada cierre debe dejar claro qué cambió, por qué cambió, qué queda abierto y qué conviene hacer después.

## 3. Uso

Usar esta plantilla al finalizar:

- un Canonization Loop
- una actualización de canon
- una tanda de documentación canónica
- una revisión de decisiones canónicas

## 4. Estructura mínima

### 4.1 Hecho

- qué se cambió
- qué documentos o artefactos se tocaron
- qué quedó completamente terminado

### 4.2 Decisión

- qué decisión se tomó
- por qué se tomó
- qué alternativa se descartó

### 4.3 Recomendación siguiente

- cuál es el siguiente paso recomendado
- por qué conviene ahora

### 4.4 Resumen del bloque

- lista compacta de acciones y decisiones
- cambios relevantes en una sola vista

### 4.5 Open items

- pendientes
- dudas
- riesgos
- cosas para revisar después

## 5. Campos recomendados

Cada resumen debería incluir, si aplica:

- `objective`
- `changed_artifacts`
- `decisions`
- `tests_or_verification`
- `open_items`
- `recommended_next_step`
- `status`

## 6. Reglas

- no ocultar incertidumbre
- no mezclar resumen con especulación
- no dejar el siguiente paso implícito
- no listar cambios sin decisión asociada
- no cerrar sin revisar si algo quedó abierto

## 7. Formato sugerido

```text
HECHO:
- ...

DECISIÓN:
- ...

RECOMENDACIÓN SIGUIENTE:
- ...

RESUMEN DEL BLOQUE:
- ...

OPEN ITEMS:
- ...
```

## 8. Relación con otros artefactos

Esta plantilla complementa:

- `100-CANONIZATION-LOOP-AND-FINAL-SUMMARY.md`
- `87-SPEC-ARCHIVE-AND-LINEAGE.md`
- `11-DECISION-RECORD-TEMPLATE.md`

## 9. No-goals

- no sustituye la verificación técnica
- no reemplaza los decision records
- no sirve para borradores intermedios sin cierre
