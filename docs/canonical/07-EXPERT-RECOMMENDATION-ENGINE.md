# Expert Recommendation Engine

## 1. Objetivo

Diseñar el sistema que recomienda qué expertos deben alimentar cada brain.

## 2. Definición

> El Expert Recommendation Engine es la capacidad de MasterMind para identificar, priorizar y justificar los expertos más adecuados para construir o mejorar un brain dentro de cualquier nicho.

## 3. Pregunta central

> ¿Quiénes son las mejores mentes para enseñar a este brain a pensar bien?

## 4. Inputs

- nicho
- subdominio
- tipo de brain
- función del brain
- geografía/mercado
- tipo de organización
- idioma

## 5. Outputs

- lista priorizada de expertos
- justificación por experto
- mapa de cobertura
- reporte de balance/sesgo
- fuentes candidatas

## 6. Criterios de selección

- relevancia
- transferibilidad
- credibilidad
- complementariedad
- aplicabilidad
- claridad doctrinal
- destilabilidad

## 7. Anti-criterios

Evitar recomendar expertos solo porque:

- son famosos
- son virales
- tienen muchos seguidores
- aparecen siempre en listas

## 8. Tipos de expertos

- fundacionales
- practitioners
- researchers
- framework builders
- domain operators
- regional experts
- institutional sources

## 9. Decisión canónica

> MasterMind debe incluir un motor formal de recomendación de expertos como parte de su capacidad de crear y mejorar brains para cualquier nicho.
