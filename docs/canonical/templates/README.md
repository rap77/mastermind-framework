# Brain Factory Templates

Plantillas operativas para materializar la capacidad de Brain Factory.

## Archivos

1. `BRAIN-REQUEST-TEMPLATE.md`
2. `BRAIN-SPEC-TEMPLATE.md`
3. `EXPERT-PACK-TEMPLATE.md`
4. `DISTILLATION-PACK-TEMPLATE.md`
5. `BRAIN-VALIDATION-TEMPLATE.md`
6. `DISCOVER-OBJECTIVE-TEMPLATE.md` — Template para crear objectives con `/mm:discover`

## Uso recomendado

1. Empezar con `BRAIN-REQUEST-TEMPLATE.md`
2. Hacer gap analysis / niche framing
3. Construir `EXPERT-PACK-TEMPLATE.md`
4. Construir `DISTILLATION-PACK-TEMPLATE.md`
5. Definir el brain final con `BRAIN-SPEC-TEMPLATE.md`
6. Cerrar con `BRAIN-VALIDATION-TEMPLATE.md`
