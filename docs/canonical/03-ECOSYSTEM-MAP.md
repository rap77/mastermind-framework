# Ecosystem Map

## 1. Objetivo

Aclarar qué rol cumple cada proyecto o influencia en la visión de MasterMind.

## 2. Principio rector

> MasterMind mantiene identidad propia, pero absorbe patrones valiosos de otros sistemas cuando ayudan a construir una mejor plataforma de brains, orquestación y aprendizaje.

## 3. Mapa general

| Sistema | Rol respecto a MasterMind | Estado |
|---|---|---|
| **MasterMind** | Núcleo del producto | Central |
| **Agent Skills** | Metodología base | Adoptado |
| **Hermes** | Referencia principal para runtime agente | Prioritario |
| **OpenClaw** | Referencia secundaria para routing/runtime autónomo | Secundario |
| **Paperclip** | Referencia principal de UX/producto/orquestación visual | Adoptado como patrones |
| **GSD** | Antecedente metodológico histórico | Reemplazado |

## 4. MasterMind

### Qué es

La plataforma principal.

### Qué aporta

- brains especializados
- conocimiento destilado
- orquestación experta
- memoria de experiencia
- Brain Factory
- compatibilidad multi-LLM
- evaluación y aprendizaje

## 5. Agent Skills

### Qué aporta

- spec-first
- SDD/spec-driven development
- `/spec`, `/plan`, `/build`, `/test`, `/review`, `/ship`
- calidad de ejecución
- workflows portables
- disciplina de implementación

### Rol en MasterMind

No define los brains; define **cómo se trabaja**.

## 6. Hermes

### Qué aporta

- memory
- MCP integration
- messaging gateway
- runtime más cohesivo
- skills
- operación multicanal

### Rol en MasterMind

Inspiración principal para la evolución del runtime operativo.

## 7. OpenClaw

### Qué aporta

- routing
- runtime autónomo
- operación programática
- ideas de plugins/herramientas
- influencia histórica del ecosistema

### Rol en MasterMind

Referencia histórica y secundaria.

## 8. Paperclip

### Qué aporta

- layouts
- experiencia de uso
- patrones visuales
- war room thinking
- componentes de interacción/operación

### Rol en MasterMind

Referencia clave de UX y operación visual.

## 9. GSD

### Qué aportó

- estructura
- workflow
- disciplina de planeación
- noción de fases/estado/verificación

### Rol actual

Parte de la historia, no del centro metodológico actual.

## 10. Relación entre capas

### Capa de identidad

- MasterMind

### Capa metodológica

- Agent Skills

### Capa de runtime agentic

- Hermes
- OpenClaw (secundario)

### Capa de UX/producto

- Paperclip

### Capa histórica

- GSD

## 11. Responsabilidades

| Área | Referencia principal |
|---|---|
| Brains especializados | MasterMind |
| Distilled knowledge | MasterMind |
| Brain learning | MasterMind |
| Brain Factory | MasterMind |
| SDD / spec-first workflow | Agent Skills |
| Runtime agent memory | Hermes |
| MCP integration patterns | Hermes |
| Messaging gateway | Hermes |
| Autonomous routing ideas | OpenClaw |
| Visual UX / orchestration patterns | Paperclip |
| Legacy workflow heritage | GSD |

## 12. Frase canónica final

> MasterMind toma de Agent Skills la metodología, de Hermes la referencia principal de runtime, de OpenClaw ideas históricas de autonomía, y de Paperclip patrones de UX y operación visual; pero su núcleo propio sigue siendo la creación, orquestación, aprendizaje y expansión de brains especializados.
