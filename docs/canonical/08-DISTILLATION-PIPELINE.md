# Distillation Pipeline

## 1. Objetivo

Definir cómo MasterMind transforma fuentes crudas de expertos en **conocimiento operativo usable por brains**.

## 2. Definición

> El Distillation Pipeline es el proceso por el cual MasterMind toma conocimiento de expertos y lo convierte en artefactos estructurados, verificables y reutilizables para crear o mejorar brains.

## 3. Principio rector

La destilación no debe producir “resúmenes bonitos”. Debe producir **capacidad de decisión**.

## 4. Fases del pipeline

```text
Source Intake
→ Source Qualification
→ Source Structuring
→ Core Extraction
→ Operational Distillation
→ Cross-Source Synthesis
→ Brain Mapping
→ Validation
→ Packaging
```

## 5. Etapas clave

### Source Qualification

Evalúa relevancia, profundidad, claridad, aplicabilidad y confiabilidad.

### Core Extraction

Extrae tesis, principios, modelos mentales, frameworks y definiciones.

### Operational Distillation

Convierte el conocimiento en:

- criterios de decisión
- señales de diagnóstico
- checklists
- heurísticas
- preguntas clave
- anti-patrones

### Cross-Source Synthesis

Detecta convergencias, tensiones, contradicciones y complementariedades.

### Validation

Valida:

- fidelidad a la fuente
- claridad
- utilidad práctica
- ausencia de alucinación
- separación entre observación e inferencia

## 6. Regla crítica

Siempre separar:

- lo que dice la fuente
- la interpretación operativa del sistema

## 7. Decisión canónica

> La destilación en MasterMind debe producir conocimiento operativo estructurado, no solo resúmenes, y debe separar explícitamente doctrina base de experiencia posterior.
